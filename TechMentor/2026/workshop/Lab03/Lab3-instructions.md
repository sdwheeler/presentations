# Lab 3 - PowerShell Module Development

1. Install the Sampler module from the PowerShell Gallery and load it into your session.
2. Create a new sample module and explore what it creates
3. Think about how you would put your module into the scaffolded structure
4. Build the module using `Invoke-Build`
5. Create a new local PSResourceRepository
6. Publish the module to the local repository
7. Inspect folder of the local repository to see what was created
8. Install module from local repository
9. Import installed module and test it
